# 校区成绩分析系统（Campus Performance Analysis）

面向单招培训机构的**多校区成绩分析 + 学习目标管理 + 高职单招大类信息查询**一体化纯前端系统。
无需后端服务器，所有数据在浏览器本地解析，可直接部署在 GitHub Pages。

> 在线访问：<https://zhangdn731.github.io/Campus_Performance_Analysis/>

---

## 一、功能特性

### 1. 多校区成绩分析（龙泉 / 星耀 / 睿智）
- 自动加载（或手动上传）各校区周测成绩 Excel，支持多班级、多次考试。
- 核心分析：综合总结、达标率统计、总成绩排名、数据明细表、分数段分布、全班成绩、个人趋势。
- 拓展分析：最高分 / 最低分、进步退步、成绩波动、分数段对比、多维度可视化图表。
- **智能分值对齐**：同一科目在不同考试满分不一致时自动换算，满分变动明确提示。
- 一键导出 PDF / CSV，支持图表与表格导出。

### 2. 学习目标（已集成进各校区）
- 在每个校区页面的标签栏中单设「**学习目标**」标签，**成绩直接复用该校区已加载的成绩文件**，无需重复上传。
- 班级筛选直接复用页面顶部「已加载班级」勾选结果，目标模块内仅保留**考试切换胶囊**与**姓名搜索**，不再重复出现班级选择器与上传/下载按钮。
- 跨已选班级合并展示总览表（含「班级」列），统计参考人数、平均总分、已设目标人数、公办/民办达标人数。
- 学生可查看：本次各科成绩、与上一次考试对比、按本次成绩预估的**可达院校 / 可达分数 / 预估位次**、学习建议。
- 工具栏支持把当前考试、当前勾选班级与姓名搜索结果一键导出为 **Excel**（含校区 / 考试 / 导出时间抬头，便于二次加工）与 **PDF**（A4 横向、长表自动分页，中文标题条不乱码）；无成绩数据时两个按钮自动禁用并提示。
- 教师在「目标院校表」中为每位学生填写**目标院校**，系统自动统计已设目标与达标情况；目标表由上传管理页统一维护，校区页面只做只读自动拉取。

### 3. 通用成绩分析
- 不绑定校区，可手动上传任意成绩 Excel 进行分析，适合临时班级或通用场景。

### 4. 大类信息（高职单招录取数据查询）
- 河北省高职单招**十大类**录取数据：院校、录取分数线、招生计划、一分一档、专业计划及学费。
- 总览看板：招生院校数、招生专业数、计划总数、平均 / 最高投档分、参考人数，以及十余张可视化图表。
- 支持按院校、专业、地区搜索与筛选，支持导出 CSV。
- **数据由年度 Excel 驱动**（`data/admission/` 下的文件 + `manifest.json`），当前为 **2026 年**数据；2027 年数据发布后，管理员直接上传对应年度 Excel，系统自动切换，无需改代码。

### 5. 首页导航与响应式
- 首页五张功能卡并入同一响应式网格：宽屏**四列**，龙泉 / 星耀 / 睿智三张校区卡在左侧通高跨两行，右侧一列上下堆叠「通用分析」「大类信息」；中屏退为两列、窄屏单列堆叠，无右侧空位。
- 适配桌面、笔记本、平板、手机等不同尺寸显示器；图表随窗口自适应缩放，宽表格在窄屏内横向滚动、不撑破页面。
- 移动端输入框字号 ≥ 16px，避免 iOS 聚焦自动缩放；靛蓝 + 青色主色调、毛玻璃卡片、粒子背景，整体风格统一。

## 三、快速开始（本地运行）

由于浏览器安全限制，`file://` 方式打开时无法通过 `fetch` 加载数据文件，**请使用本地 HTTP 服务器**：

```bash
# 进入项目根目录
cd Campus_Performance_Analysis

# 方式一：Python（推荐）
python -m http.server 8765

# 方式二：Node
npx serve .
```

然后在浏览器访问：<http://localhost:8765/>

## 四、数据更新指南

### 1. 更新校区成绩
- 登录 `pages/upload.html`（校区账户或管理员），在成绩上传区块选择最新成绩 Excel，上传前可预览班级数、考试数、学生数、科目数。
- 校区账户只能上传本校区成绩；管理员根据文件名中的「龙泉 / 星耀 / 睿智」字样自动识别写入对应文件：
  `data/27届龙泉周测成绩.xlsx`、`data/27届星耀周测成绩.xlsx`、`data/27届睿智周测成绩.xlsx`。
- 校区页面内也可手动选择成绩文件做**本地解析预览**，该操作不写入仓库。

### 2. 上传学习目标（目标院校表）
1. 登录 `pages/upload.html`，在「上传目标院校表（学习目标）」区块下载 `目标院校填写模板.xlsx`。
2. 按班级（每个班级一个工作表）填写每位学生的「姓名 / 目标院校」两列。
3. **管理员**可在校区下拉中选择龙泉 / 星耀 / 睿智任一校区；**校区账户**自动固定为本校区，不可更改。
4. 选择填写好的 `.xlsx` 文件，预览显示班级工作表数与已填目标人数，确认后上传到 `data/targets/{校区}目标.xlsx`。
5. 对应校区「学习目标」页刷新后自动拉取最新目标表；GitHub Pages 缓存约 1–2 分钟生效。

> 目标院校名称需与系统院校库中的名称一致，系统会自动匹配并显示目标分数；未上传目标表时，状态条提示「目标院校表尚未上传」，成绩与排名仍可查看，目标匹配列留空。未加载成绩或未勾选班级时，模块显示「暂无成绩数据」空态提示。

### 3. 更新大类年度数据（如 2027）
1. 进入「大类信息」页面，点击右上角「**上传数据(管理员)**」。
2. 输入管理员令牌登录。
3. 选择准备好的年度 Excel（工作表结构：`00-类别说明` + 每类 `{编号}-院校 / 分数线 / 招生计划 / 一分一档 / 专业学费`）。
4. 系统自动识别年度，确认后上传为 `data/admission/河北单招数据_{年份}.xlsx`，并更新 `manifest.json`，页面刷新为该年度。
5. 历史年度文件保留在仓库中，可通过修改 `manifest.json` 切换。

## 五、账户与权限

`pages/upload.html` 内置账户（密码以 SHA-256 哈希存储）：

| 账户 | 角色 | 权限 |
| --- | --- | --- |
| `admin` | 管理员 | 三校区成绩上传、三校区目标院校表上传；大类年度数据在「大类信息」页用独立管理员令牌上传 |
| `longquan` | 龙泉校区 | 龙泉校区成绩上传、龙泉校区目标表上传（不可切换校区） |
| `xingyao` | 星耀校区 | 星耀校区成绩上传、星耀校区目标表上传（不可切换校区） |
| `ruizhi` | 睿智校区 | 睿智校区成绩上传、睿智校区目标表上传（不可切换校区） |

> 上传管理页登录仅做账户名 + 密码（SHA-256 哈希）校验；GitHub API 令牌在页面内以反转 + Base64 混淆方式内置，仅用于本仓库读写，不在页面上明文展示。登录态保存在当前标签页 `sessionStorage`，关闭标签页即清除。

## 六、技术栈

- 原生 **HTML / CSS / JavaScript**，无构建工具、无框架。
- [ECharts](https://echarts.apache.org/) / Chart.js：数据可视化（CDN 加载，含降级兜底）。
- [SheetJS（xlsx）](https://sheetjs.com/)：Excel 解析与生成。
- html2canvas + jsPDF：PDF 导出。
- GitHub Contents API：数据文件托管；GitHub Pages：静态托管。

## 七、部署到 GitHub Pages

1. 将项目推送到 GitHub 仓库（默认分支 `main`）。
2. 仓库 **Settings → Pages → Build and deployment → Source 选择 `Deploy from a branch`，分支选择 `main` / 根目录**，保存。
3. 等待约 1 分钟，即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。
4. 仓库已包含 `.nojekyll`，确保以下划线开头的资源不被忽略。

大文件推送建议配置：

```bash
git config http.postBuffer 524288000
git config http.version HTTP/1.1
git config core.quotepath false
```

## 八、常见问题

- **页面提示「未找到成绩文件」**：该校区成绩 Excel 尚未上传到 `data/` 目录，可手动上传或联系管理员。
- **打开是空白 / 数据不加载**：多为直接用 `file://` 打开导致，请改用本地 HTTP 服务器或访问已部署的在线地址。
- **上传提示令牌无效**：大类信息页上传需输入具备 `repo` 权限的 `ghp_` 令牌；上传管理页使用页面内置令牌，若失败多为网络波动或令牌过期，联系管理员更新。
- **目标院校未匹配**：核对填写的院校名称是否与院校库完全一致。

## 九、数据安全与免责声明

- 本系统为纯前端应用，成绩与目标数据仅在浏览器本地解析，除管理员主动上传到自己的 GitHub 仓库外，不会发送到任何第三方服务器。
- 录取数据来源为河北省教育考试院及公开招生信息，**仅供教学参考，最终以官方公布为准**。
